# EcomWeb - E-Commerce Website

A modern, responsive e-commerce website built with HTML, CSS, and JavaScript. Designed for GitHub Pages hosting.

## Features

- **Home Page** — Hero banner, categories, featured products, newsletter
- **Product Catalog** — Browse all products with category filtering and search
- **Product Details** — Detailed product view with quantity selector and related products
- **Shopping Cart** — Full cart with add/remove, quantity update, order summary, and checkout
- **About Page** — Company story, mission, and stats
- **Contact Page** — Contact form with info cards
- **Responsive Design** — Fully mobile-friendly across all devices
- **Client-side Cart** — Cart persists via localStorage

## Tech Stack

- HTML5
- CSS3 (Custom properties, Grid, Flexbox)
- Vanilla JavaScript (ES6+)
- No external frameworks or build tools required

## Project Structure

```
├── index.html           # Home page
├── products.html        # Product catalog
├── product-detail.html  # Product detail page
├── cart.html             # Shopping cart
├── about.html           # About page
├── contact.html         # Contact page
├── css/
│   └── styles.css       # All styles
├── js/
│   ├── app.js           # Navigation, header/footer, product cards
│   ├── cart.js           # Cart class + toast notifications
│   └── products.js      # Product data

```

## Getting Started

Simply open `index.html` in a browser, or deploy to GitHub Pages.
